┌──────────────────────────────────────────────────────────────────────────────┐
│ 📞 SOPORTE Y TROUBLESHOOTING                                                │
└──────────────────────────────────────────────────────────────────────────────┘

"No se conecta a localhost:8081"
  → Verificar que ms-gestionpacientes esté corriendo
  → Revisar puerto correcto
  → Limpiar Maven cache: mvn clean

"CORS Error en frontend"
  → Verificar que BFF esté en puerto 8080
  → Revisar headers en HttpClient

"Datos no persisten"
  → Si usas H2: Es esperado, datos se pierden al restart
  → Si usas PostgreSQL: Verificar conexión a BD

"Componente no carga"
  → Revisar npm install completado
  → Limpiar npm cache: npm cache clean --force
  → Eliminar node_modules y reinstalar

Para más: Ver GUIA_EJECUCION.md sección "Solución de Problemas"
