## 🚀 Cómo Empezar

### Paso 1: Instalar (3-5 minutos)
```bash
cd Fullstack-III-EFT-Frontend

npm install --save-dev \
  vitest \
  @testing-library/react \
  @testing-library/jest-dom \
  @testing-library/user-event \
  jsdom \
  @vitest/coverage-v8
```

### Paso 2: Ejecutar (1 minuto)
```bash
npm test
```

Deberías ver: ✅ 160+ tests ejecutados exitosamente

### Paso 3: Ver Cobertura (1 minuto)
```bash
npm run test:coverage
open coverage/index.html
```
