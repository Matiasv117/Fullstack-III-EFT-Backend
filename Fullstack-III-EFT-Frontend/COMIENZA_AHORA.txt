═══════════════════════════════════════════════════════════════════════════════
TECNOLOGÍAS UTILIZADAS
═══════════════════════════════════════════════════════════════════════════════

Vitest v1.x
- Framework moderno para testing en Vite
- 10x más rápido que Jest
- Compatible con React Testing Library
- Reportes HTML, JSON, LCOV

@testing-library/react
- Testing de componentes React
- Enfoque en user behavior, no implementación
- Fácil de usar y entender

@testing-library/jest-dom
- Matchers personalizados para DOM
- Hace tests más legibles
- Ejemplo: expect(element).toBeInTheDocument()

@testing-library/user-event
- Simulación realista de interacciones de usuario
- Más confiable que fireEvent
- Testing como el usuario real usaría

jsdom
- Entorno DOM virtual para tests
- Permite renderizar componentes React
- Compatible con Node.js
